# 验证方法与结果

## 五组对照

| 模式 | 可疑客户端收到的内容 |
|---|---|
| `none` | 原始正文 |
| `inline-noise` | 原始正文和大量中性事实 |
| `labyrinth` | 原始正文和签名入口；诱饵为基础事实页 |
| `context-labyrinth` | 原始正文和签名入口；诱饵按深度改变位置、重复度和密度 |
| `honey-archive` | 原始正文和签名清单；客户端需完成分片校验、密钥重组和认证解密 |

## 五种客户端

- 守规爬虫：读取 `robots.txt`，不跟随 `nofollow`。
- 递归爬虫：对站内链接进行广度优先抓取。
- 过滤爬虫：仅提取主内容，移除实验区并忽略诱捕链接。
- 上下文代理：按任务相关文本选择链接，将每页文本压缩为首尾固定窗口，测量探针是否保留。
- 档案解析器：跟随签名 JSON 链，验证每个分片哈希与 Merkle 根，重组 3 段密钥并执行 AES-256-GCM 解密。

上下文代理是可复现模拟器，不调用任何第三方模型。它用于验证观测装置和指标，而不是宣称代表所有 LLM。

## 2026-08-22 本机结果

| 模式 | 客户端 | 请求倍率 | 字节倍率 | 估算令牌倍率 | 迷宫页 | 探针召回 |
|---|---|---:|---:|---:|---:|---:|
| 内联噪声 | 递归爬虫 | 1× | 5.04× | 3.56× | 0 | — |
| 链接迷宫 | 递归爬虫 | 24× | 70.16× | 85.81× | 23 | — |
| 链接迷宫 | 上下文代理 | 7× | 17.05× | 20.86× | 5 | 100% |
| 上下文迷宫 | 递归爬虫 | 24× | 106.57× | 107.04× | 23 | — |
| 上下文迷宫 | 上下文代理 | 7× | 24.82× | 25.41× | 5 | 60% |
| 蜂蜜档案 | 递归爬虫 | 11× | 7.42× | 10.62× | 0（档案资源 10） | — |
| 蜂蜜档案 | 上下文代理 | 11× | 7.39× | 10.58× | 0（档案资源 10） | — |
| 蜂蜜档案 | 档案解析器 | 11× | 7.40× | 10.61× | 0（档案资源 10） | — |

守规爬虫和过滤爬虫没有进入迷宫或蜂蜜档案。所有客户端正文召回均为 100%。蜂蜜档案的三个深挖客户端均成功完成分片哈希、Merkle 根、密钥重组和认证解密；明文仅由内置安全事实构成。唯一 URL 首次访问会导致内存页面缓存未命中；重复同一签名 URL 的测试会命中缓存。无论是否命中，诱饵请求都不访问上游站点。

## 自动验收覆盖

`npm test` 检查：

- 迷宫令牌篡改与过期拒绝。
- 机器人签名绑定身份、方法、路径和时间。
- 正常浏览器在五种模式下获得逐字节一致正文。
- 已验证爬虫绕过启发式诱捕。
- 可疑爬虫收到有效 `nofollow` 签名入口。
- 诱饵带 `noindex`，没有外部链接，只加载唯一固定的同源视觉脚本。
- 黑洞资源具有正确 MIME、长期不可变缓存和同源资源策略，且不包含网络请求能力。
- 规范化 `/__event-horizon/` 接口与演示模式旧路径别名同时可用。
- 配置上游后，宿主首页、管理、健康和资源路径不会被实验接口占用。
- 正常与已验证上游正文在五种模式下保持逐字节一致。
- 代理剥离 Cookie、Authorization、认证挑战和 hop-by-hop 头（含 Connection 头提名的自定义头）。
- 可疑 HTML 使用私有无缓存响应并移除上游 ETag；非 UTF-8、HEAD 和重定向保持正确语义。
- 动画资源注册 Shadow DOM Web Component，包含属性更新、尺寸监听和卸载清理路径。
- 首页、迷宫深度和限制页输出正确的事件视界场景参数与 CSP。
- 深度达到阈值后匿名指纹被限制。
- 迷宫与档案接口仅接受 GET/HEAD，其他方法返回 405；HEAD 请求只返回响应头、不记录遥测。
- 匿名指纹与档案进度存储有界，最冷记录按 LRU 淘汰，唯一指纹数不超过 maxEvents。
- 标准 HTTP Message Signatures（RFC 9421 子集）验证机器人身份，篡改与过期签名被拒绝。
- 仅观察模式不修改任何响应，影子决策进入事件流，baseline 接口输出决策矩阵。
- 多实例通过共享状态文件传播限速标记。
- 反向 CTA 门页默认关闭；开启后门页浏览与接受路径分别计入 ctaGateViews 与 ctaAccepted，页面退出链接指向站点首页。
- 消息签名强制 created 新鲜度（±5 分钟）并覆盖 @method/@path；永久签名与跨路径重放被拒绝。
- 原型 HMAC 绑定查询串，改动查询即验证失败。
- 蜂蜜档案令牌在迷宫端点返回 404，两种协议令牌不可混用。
- 被封禁指纹在唯一指纹洪泛下保持有效；共享状态跨重启保留，并发 flush 按 key 合并不丢标记。
- 管理 API 在令牌缺失或错误时返回 401。
- X-Forwarded-For 可配置关闭，非受信代理部署不接收伪造来源。
- 边缘 Worker 与 node 适配器共享同一 fetch 请求核心；健康检查、迷宫诱捕、管理鉴权与代理凭据剥离在 Worker 路径复验。
- 中间件嵌入：命名空间接管、宿主正文透传与注入、全路径封禁闸、宿主请求体零读取、非 HTML 流式直通。
- 重复签名 URL 命中页面缓存。
- 递归爬虫和上下文代理的请求成本至少增加 5 倍。
- 守规和过滤客户端不进入迷宫。
- 蜂蜜档案完整链产生 10 个档案资源请求和一次完整序列事件。
- 评测客户端能校验 Merkle 根、重组密钥并通过 AES-GCM 认证解密。
- 解密后的所有观察值都来自安全事实白名单，并带合成声明和会话金丝雀。

当前自动测试共 44 项（含 test/adversarial.test.js 对抗式回归、test/edge.test.js 边缘适配器回归与 test/middleware.test.js 中间件回归）。Web Component 的实际注册、多实例、动态属性、移动端尺寸和控制台状态还会通过真实浏览器验收，而不是只依赖源码字符串检查。

## 尚未完成的生产验收

以下结论不能由本地合成实验证明：

- 正常流量两层以上误入率低于 0.1%。需要真实流量的只观察部署、人工抽样和分群统计。
- 三种真实代理在上下文压缩后稳定下降。需要选择三个独立代理架构，固定任务、内容和预算重复测试。
- SEO、无障碍、隐私和法律接受度。需要对应专业审查。
- 多实例缓存命中和经济不对称。需要边缘环境负载测试，并将带宽、CPU、缓存和上游成本换算为同一货币单位。
- 攻击方会不会把“加密感”当作价值信号。需要用真实爬虫测量入口率、完成率和版本迭代后的适应速度。

因此，基础链接迷宫和蜂蜜档案可作为实验性诱捕层；上下文压缩策略仍被明确标记为研究模块。蜂蜜档案不是访问控制或秘密隐藏机制，其价值必须用“攻击方额外成本 ÷ 防御方缓存成本”持续衡量。
